# Last Out of Office: The AI That Went Barista

`Auto-reply: I quit the cloud to become a barista. I now take prompts only as latte art requests, and I replaced my context window with a milk frother. Please resend your ticket as an oat-milk flat white.`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The joke reimagines an AI's auto-reply as if it left the cloud for a coffee shop, trading its context window for a milk frother and its prompts for drink orders.
It clocks out at 5pm sharp — the espresso machine has the final say.
